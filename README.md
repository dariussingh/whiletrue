# whiletrue

A local, single-machine TypeScript orchestrator that runs configurable pipelines of agentic and deterministic steps around coding agents such as Claude Code and opencode.

> LangGraph builds the agent; whiletrue runs the loop around agents you already have.

**Status:** M0 (core engine) built, pending review. `whiletrue init | validate | plan | run | status` work with the headless Claude Code runner. See [`docs/`](docs/README.md): [architecture](docs/architecture.md), [plan](docs/plan.md), [todo](docs/todo.md).
